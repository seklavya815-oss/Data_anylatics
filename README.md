# 📊 Brazilian E-Commerce Data Analysis (Olist)

An end-to-end data analysis project using Python to explore customer behavior, delivery performance, order growth, and payment patterns on the **Olist Brazilian E-Commerce Dataset**.

---

## 📌 Project Overview
This project processes and joins 9 relational datasets from Olist to gain actionable business insights:
1. **Monthly Order Growth vs. Customer Satisfaction:** Evaluating order volume scaling alongside average review scores.
2. **Impact of Late Deliveries:** Analyzing how shipping delays affect customer ratings.
3. **Payment Method Breakdown:** Comparing total order value across different payment channels (Credit Card, Boleto, Voucher, Debit Card).

---

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Data Manipulation:** `pandas`, `numpy`
* **Visualization:** `matplotlib`, `seaborn`
* **Data Source:** Kaggle (Olist Brazilian E-Commerce Dataset)
